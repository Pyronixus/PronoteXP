# 🚀 Quickstart

PronoteXP can be used in two ways: directly in the browser through the hosted app, or locally from this repository.

## 1. Use the hosted version

No installation required.

1. Open the public GitHub Pages frontend.
2. Select the login mode you want to use:
   - QR Code
   - Token / URL
   - Credentials
3. Enter the required values and click **Export data**.
4. In the category selector, choose the data you want to export.
5. Pick the output format: Excel (`.xlsx`) or LibreOffice (`.ods`).
6. If needed, enable the split-files mode to generate one file per category and remove those selected categories from the main JSON export.

> The first request may take a few seconds while the Render backend wakes up.

## 2. Run locally with `run.py`

Requirements: **Python 3.9+**.

```bash
git clone https://github.com/<your-org>/pronotexp.git
cd pronotexp
python run.py
```

On Windows, if `python` is not recognized, try:

```bash
py run.py
```

What `run.py` does:

1. Creates a virtual environment in `venv/` if it does not exist.
2. Installs dependencies from `backend/requirements.txt`.
3. Starts the backend server with Uvicorn in reload mode.
4. Serves the frontend directly from the FastAPI app at `http://localhost:8000`.

Then open:

```text
http://localhost:8000
```

## Login modes

| Mode            | Required fields                                  |
| --------------- | ------------------------------------------------ |
| **QR Code**     | PRONOTE QR code image + 4-digit PIN              |
| **Token / URL** | PRONOTE URL + username + session token           |
| **Credentials** | PRONOTE URL + username + password + optional ENT |

### QR Code mode

- Upload the QR code generated by the PRONOTE mobile app.
- Enter the 4-digit PIN linked to the session.
- The QR payload is decoded in the browser before sending the request to the backend.

### Token / URL mode

- Provide the PRONOTE URL of your establishment.
- Enter the username and the session token.

### Credentials mode

- Provide the PRONOTE URL.
- Enter your username and password.
- The `ENT` field is optional and can be left blank depending on your configuration.

## After the export

Once the request is successful:

- the JSON export is available for download,
- the category list is updated with empty/non-empty states,
- a workbook can be generated in `.xlsx` or `.ods`,
- if split-files mode is enabled, each selected category becomes its own JSON and sheet export.

## Stop the server

In the terminal, press:

```text
Ctrl + C
```

To restart Uvicorn without stopping the launcher, press:

```text
Ctrl + R
```

The current server process and its reload subprocess are stopped before the new instance starts.

To stop the server while keeping the virtual environment and Python caches for the next launch, press:

```text
Ctrl + Alt + C
```

## Troubleshooting

- If the frontend cannot connect to the backend, verify that the app is running on port `8000`.
- If Python is missing from `PATH`, use `py` instead of `python` on Windows.
- If the Render instance is sleeping, the first request may take longer than usual.
